The file contains a dataset of 62 contentious cases before the International Court of Justice (ICJ) in which the ICJ: (a) rendered a final judgment on merits, and (b) imposed positive or negative obligation(s) capable of substantive compliance.
I record the follwing variables in the dataset: (i) name of the case/dispute in which the judgment was rendered, (ii) whether Applicant before the ICJ in each dispute was a Global South or Global North State, (iii) whether Respondent before the ICJ in each dispute was a Global South or Global North State, (iv) wehther there existed a relative geopolitical power differential between the two parties, (v) whether the judgment was followed by substantive and timely compliance by the party on which such obligation of compliance was imposed.
